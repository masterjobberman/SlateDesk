# SlateDesk 1.6 full release

- [Windows portable build](https://github.com/masterjobberman/SlateDesk/releases/download/v1.6.0/SlateDesk-1.6-Windows-x64.zip)
- [GitHub release page](https://github.com/masterjobberman/SlateDesk/releases/tag/v1.6.0)
- `SlateDesk-1.6-Windows-x64.zip`: EXE, all runtime dependencies, documentation, licenses and source.
- `SlateDesk-1.6-Source.zip`: corresponding application source and build instructions.
- `SHA256SUMS.txt`: checksums for both ZIPs.

Extract the full Windows ZIP, then run SlateDesk/SlateDesk.exe. Never copy the EXE alone. No Python installation is needed. Binaries are unsigned; hardware limitations remain documented in the main README and validation notes. Archive documentation includes the upstream-checksum correction at commit 598d302; runtime code is unchanged from the v1.6.0 tag.
