# Changelog

## 1.6 — 2026-11-24

First GitHub release of the developed SlateDesk application.

- Get all / Get oldest / Get newest and an explicit delete-after-transfer checkbox.
- Safe failure when later pages cannot be reached without deletion; newest opens the last transferred page while keeping earlier local backups.
- Large portrait preview with Pages, Device and Transfer sidebar tabs.
- Purple/blue theme, rounded panels and larger Calibri typography.
- Remembered registrations and Windows paired-device discovery.
- Live transfer counters, stage labels, idle warnings, cancellation and diagnostics.
- Local raw/JSON storage and SVG, PNG and PDF export.

Earlier local iterations introduced the protocol transport, portable Windows packaging, progress display, portrait defaults and device remembering. They were not separate GitHub releases. Full multi-device/firmware hardware acceptance remains outstanding.
